# Contributing

Read the project's README and any repository-specific contribution guidelines before getting started.

## Issues

Search existing issues before opening a new one. Report bugs with reproducible steps, expected and actual results, and relevant version and environment details. For feature requests, describe the use case and the problem you want to solve.

## Pull requests

1. Discuss substantial changes in an issue before starting implementation.
2. Fork the repository if needed, then create a branch and keep each pull request focused on one change.
3. Follow the project's existing structure and style, run relevant checks, and update documentation when needed.
4. Describe the change, link related issues, and include validation results. Explain any checks you could not complete.
